## 🆕 功能变化

### 🔥 影火AI 多模态分析 + 一键生成报告

- **影火AI 对话**：患者端与影火AI 的多轮对话，具备上下文记忆能力
- **视频理解**：基于摄像头实时数据（YOLO 目标检测 + DeepSeek 场景分析），AI 能识别环境中的物体和异常
- **一键生成患者行为分析报告**：监护人端点击"生成报告"，服务器汇总以下数据自动生成：
  - 摄像头视觉标签（YOLO 检测到的物体/场景）
  - 影火AI 对话记录（患者与AI 的交互内容）
  - 麦克风转录文本（语音识别结果，暂未接入硬件麦克风）
- **危险检测**：后台 AI 自动分析，检测到跌倒/无响应/异常音频时向监护人推送告警

### 📹 双摄像头来源自动兜底

- **主路**：手机 IP Webcam 软件推流 → `http://<手机IP>:5000/video_feed`
- **兜底路**：M5Stack ESP32 鱼眼摄像头 → `http://<ESP32_IP>:81/stream`
- **自动切换**：主路连接失败时 3 秒内自动探测并切换到兜底路，无需手动干预
- **手动切换**：视频通话界面点击"切换摄像头"按钮可在两路之间手动切换
- **来源标识**：通话界面显示当前使用的摄像头来源（"IP摄像头" / "ESP32鱼眼"）
- **偏好持久化**：可在设置中指定首选摄像头，下次启动自动生效

### 📱 前后端联调

- 手机摄像头 MJPEG 推流 → Flask 视觉服务（YOLO 标注）→ WebSocket 中转 → 监护人端实时画面
- 摄像头调用链路已打通：患者端触发推流 → 服务器下发 stream_url → 监护人端拉流显示

## 🔧 配置变更

### 新增 `.env.example` 模板

队友拉取代码后执行 `cp .env.example .env`，然后修改为自己的配置：

| 变量 | 说明 | 示例 |
|------|------|------|
| `SERVER_HOST` | 后端服务器 IP | `192.168.1.100` |
| `SERVER_PORT` | WebSocket 端口 | `8000` |
| `ROOM_ID` | 房间号 | `1234` |
| `CAMERA_SOURCE` | 摄像头数据源 | IP Webcam / ESP32 / 本地摄像头 |
| `MJPEG_STREAM_URL` | YOLO标注后视频流 | `http://<IP>:5000/video_feed` |
| `DEEPSEEK_API_KEY` | DeepSeek API 密钥 | `sk-...` |

## ⚠️ 已知限制

- **手机麦克风调用尚未实现**：报告中的音频转录部分当前使用模拟数据，硬件麦克风接入待后续版本
- **ESP32 鱼眼摄像头的具体 URL 取决于固件版本**：默认假设 `:81/stream`，如你的 ESP32 固件不同，需在 App 设置中填写自定义摄像头地址

## 🚀 安装

```bash
adb install 历代稳定版\YinBan_v1.5.apk
```

## 🐍 后端启动

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑 .env 填自己的 IP 和密钥

# 2. 启动后端服务器
cd 后端
python main.py

# 3. 启动视觉服务（需要 YOLO 模型）
cd 硬件
python main_visual_service.py
```
